Las guías del [catálogo de módulos](../README.md) detallan los casos de prueba
y las brechas de cada flujo.

## Cómo repetir las pruebas

Desde la raíz del repositorio, con las dependencias de `frontend`, Google
Chrome y el componente de grabación de Playwright instalados:

```sh
python3 scripts/run_module_qa.py all --headless --pause-ms 1600 --action-ms 125 --workers 2
```

El ejecutor genera resultados JSON, capturas, grabaciones y un informe HTML
en `frontend/playwright-report/qa-modulos-<id>/`. Los
[scripts por módulo](../../scripts/qa-modulos/) permiten grabar un recorrido
individual. Para la API, PostGIS y la suite de escritorio y móvil, usa
[el ejecutor de QA conectado](../../frontend/tests/manual-agricultural-workflow.md#pruebas-automatizadas-en-chrome).
